# 수학송 가사 스튜디오 — 설정 안내서

중3 학생이 단원을 골라 가사를 쓰고, Suno로 노래를 만든 뒤 선생님의 패들렛에 올리는 웹앱입니다.
학생은 로그인 없이 쓰고, 데이터베이스나 서버가 필요 없습니다.

## 바로 쓰기 (이미 올려진 사이트를 쓰는 선생님)

1. 사이트의 `setup.html` 페이지(학생 화면 맨 아래 **“우리 반 학생용 링크 만들기”**)를 엽니다.
2. 선생님 패들렛 주소를 넣고 **학생용 링크 만들기**를 누릅니다.
3. 나온 링크나 QR코드를 학생들에게 알려 주면 끝입니다. 학생 화면의 ‘패들렛 열기’가 선생님 패들렛으로 연결됩니다.

패들렛 준비: 형식은 **열(Columns)**, 섹션 이름은 `1반`, `2반` … 처럼 반별로, 공유 설정은 **링크가 있는 사람이 글쓰기 가능**으로 해 주세요.
반별로 나누지 않았다면 링크를 만들 때 “반별 열로 나눴어요” 체크를 끄면 됩니다.

## 학생 화면

- 맨 위: 선생님이 만든 완성 예시 「동그라미 공식」(원의 성질)과 노래 듣기
1. 우리 팀 정보 (반, 번호, 이름 1~2명)
2. 단원 고르기 (7개 단원, 핵심 개념과 후렴에 넣기 좋은 말)
3. 노래 스타일 고르기 (Suno 스타일 예시 10가지)
4. 가사 쓰기 ([Verse]/[Chorus] 버튼, 체크 표시)
5. Suno에서 노래 만들기 (가사·스타일·제목 복사)
6. 패들렛에 올리기 (노래 링크 입력 → 제목, 가사·링크 복사 → 자기 반 열에 올리기)

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html`, `app.js` | 학생 화면 |
| `setup.html` | 선생님용: 패들렛 주소로 학생용 링크·QR코드 만들기 |
| `data.js` | 단원 핵심 개념, Suno 스타일 예시 10개, 완성 예시 곡 (바꾸고 싶을 때만) |
| `config.js` | 기본 패들렛 주소 (비워 두면 됨) |
| `style.css` | 디자인 |

## 내 GitHub에 직접 올리기 (약 5분)

1. https://github.com 로그인 → 오른쪽 위 **+ → New repository** → 이름 예: `mathsong` → **Public** → **Create repository**
2. **uploading an existing file**을 누르고, 압축을 푼 `mathsong-web` 폴더 **안의 파일들**을 끌어다 놓기 → **Commit changes**
3. **Settings → Pages** → Source: `Deploy from a branch`, Branch: `main` / `(root)` → **Save**
4. 1~2분 뒤 주소가 나옵니다: `https://<아이디>.github.io/mathsong/`
5. `https://<아이디>.github.io/mathsong/setup.html`에서 학생용 링크를 만드세요.

## 알아 두면 좋은 점

- 학생용 링크에는 패들렛 주소가 들어 있어서, 링크를 받은 사람은 패들렛 주소(비밀번호 포함)를 볼 수 있습니다. 우리 학생들에게만 알려 주세요.
- 학생 화면은 쓰던 내용과 패들렛 주소를 그 브라우저에 기억합니다. 컴퓨터실처럼 여러 반이 같은 컴퓨터를 쓰면 다 올린 뒤 내용을 지우게 해 주세요.
- Suno 사용 연령·약관(만 13세 이상 등)과 학교 정책은 수업 전에 확인해 주세요.
